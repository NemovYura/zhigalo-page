# Страница врача — Жигало А. В.

Прототип страницы врача для сайта Медицинского центра Елены Малышевой.
Свёрстан по макету из Figma (UI-кит), с анимациями и ховерами.

- `index.html` — вся страница в одном файле, изображения встроены
- адаптив: 1440 → 375 px, тёмная тема, учёт «уменьшить движение»

Публикация: Settings → Pages → Deploy from a branch → `main` / `(root)`.
